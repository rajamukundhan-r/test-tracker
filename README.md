# Calorie Tracker

A minimal dark-mode calorie and weight tracker. One file (`index.html`), no build step, no dependencies. Open it in a browser, or host it on any static host (e.g. GitHub Pages).

- **Today** – calorie ring, protein/carb/fat split, four meals, quick weigh-in.
- **Add food** – search 230+ foods and ingredients, pick an exact amount in g, oz or a natural measure (cup, tbsp, slice, piece…). Calories and macros are calculated live before you add.
- **Weekly / Monthly** – calorie bar charts against your target, averages, days on target, macro split, weight trend and breakdown tables.
- **Weight** – log weigh-ins, trend chart with goal line, progress to goal.
- **Foods** – browse the database and create custom foods (per 100 g plus an optional serving size).
- **Settings** – kg/lb, lose/maintain/gain goal and pace, calorie-target suggestion (Mifflin-St Jeor), JSON backup/import.

Data is stored in your browser's `localStorage`; use Settings → Export backup to move it between devices. Nutrition values are typical averages (per 100 g) and are estimates.
